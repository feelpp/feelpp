Detailed Description

Symmetric tensor storage, output-order, and scaling utilities.

This header centralizes field-level symmetric tensor conventions used by matrix fields and exporters. It deliberately depends only on low-level Feel++ traits for the legacy packed storage index and does not pull in VF expression machinery.
