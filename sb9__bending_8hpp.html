Build the SB9 membrane-plus-bending Mandel strain expression.

This helper combines the membrane and bending coefficient expressions as Bm0 + zeta * Bb0 in the in-plane symmetric-storage entries and returns a six-component Mandel vector with out-of-plane components set to zero.
