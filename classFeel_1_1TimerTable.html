Detailed Description

Local timer statistics and their text, Markdown, and journal reports.

Each tic()/toc() call updates this table locally. Gather profiles only after the timed work; every rank in the communicator must call the gather with the same labels and rank selection. Rank IDs are local to that communicator. The pooled profile combines every call from the selected ranks for each label.

Record repeated calls under one or more labels
#include <feel/feeltiming/tic.hpp>
auto const& comm = Feel::Environment::worldComm().localComm();
Feel::tic();
// Assemble a system.
Feel::toc( "assembly", Feel::no_display );
Feel::tic();
// Solve the system.
Feel::toc( "solve", Feel::no_display );
