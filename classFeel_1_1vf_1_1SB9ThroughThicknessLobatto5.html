Detailed Description

template<typename T = double>
class Feel::vf::SB9ThroughThicknessLobatto5< T >

Reduced Gauss-Lobatto quadrature through the SB9 shell thickness.

This rule is tailored to the SB9 stiffness terms. It places all points at the in-plane reference center, \((\xi,\eta)=(0,0)\), and uses the five-point Gauss-Lobatto rule in the thickness coordinate \(\zeta\):

\[ \zeta = \left(-1,-\sqrt{3/7},0,\sqrt{3/7},1\right). \]

The one-dimensional weights are scaled by the in-plane reference measure \(4\), so the total weight is \(8\), the measure of the reference hexahedron \([-1,1]^3\).
