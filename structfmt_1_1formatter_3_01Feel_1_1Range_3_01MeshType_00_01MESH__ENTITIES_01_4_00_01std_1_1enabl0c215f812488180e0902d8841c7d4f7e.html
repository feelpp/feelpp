Detailed Description

template<typename MeshType, int MESH_ENTITIES>
struct fmt::formatter< Feel::Range< MeshType, MESH_ENTITIES >, std::enable_if_t< std::is_base_of_v< Feel::MeshBase<>, MeshType >, char > >

Formatter specialization for Feel::Range.

This struct provides a custom formatter for Feel::Range objects, enabling them to be formatted using the {fmt} library.

Template Parameters
MeshTypeThe type of the mesh.
MESH_ENTITIESThe number of mesh entities.

This formatter is enabled only if MeshType is derived from Feel::MeshBase.
