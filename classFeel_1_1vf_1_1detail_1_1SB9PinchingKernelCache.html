Detailed Description

template<typename GeometryDataType>
class Feel::vf::detail::SB9PinchingKernelCache< GeometryDataType >

Element-local cache for SB9 pinching coefficients.

The cache reuses SB9KernelBase for frame and Jacobian data and computes the pinching coefficients. The resulting coefficients are later projected into Mandel symmetric storage by fillVectorCoefficients.

Template Parameters
GeometryDataTypeShell cell geometry cache type provided by ShellCellGeometryTensorBase.
