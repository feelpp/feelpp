◆ setDirichletInPlace()

template<typename T = double>
void Feel::BilinearFormBase< T >::setDirichletInPlace ( bool  value)

Select whether deferred Dirichlet constraints modify the matrix in place.

The default (true) avoids cloning the complete sparse matrix. Ordinary row elimination needs no auxiliary matrix data. Symmetric elimination retains only the sparse Dirichlet-column entries needed to refresh the right-hand-side contribution when prescribed values change. Passing false preserves the unconstrained matrix and materializes a separate constrained matrix for compatibility or inspection purposes. The policy must be selected before constraints are materialized.
