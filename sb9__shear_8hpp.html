enum class Feel::vf::detail::SB9ShearKind

Selects an SB9 transverse-shear coefficient block.

Bc0 is the physical transverse-shear operator used in the SB9 elastic strain. Bc1 and Bc2 are the two Hallquist transverse-shear stabilization blocks used by the stabilized formulation.

Enumerator
Bc0 

Physical transverse-shear block contributing to eps_xz and eps_yz.

Bc1 

First transverse-shear stabilization block.

Bc2 

Second transverse-shear stabilization block.

template<detail::BasisProxyType ProxyType>
auto Feel::vf::sb9Bc0 ( ProxyType const &  proxy)

Build the physical SB9 transverse-shear coefficient expression.

The returned expression is the Bc0 block used to assemble the physical transverse-shear strain contribution. It is a six-component compact symmetric vector expression in the same storage convention as the other SB9 strain blocks.

Example
auto shearWeight = cst( 5.0 / 4.0 ) * ( cst( 1.0 ) - zeta()*zeta() );
auto epsS = sb9Shear( u, shearWeight );
a += integrate( _range=elements( mesh ),
_quad=sb9ThroughThicknessLobatto5(),
_expr=ddot( C, epsS, sb9Shear( v, shearWeight ) ) );

Build the first SB9 transverse-shear stabilization block.

Bc1 is not part of the physical strain vector. It is used in the Hallquist transverse-shear stabilization term, typically together with sb9Bc2.

Example
a += integrate( _range=elements( mesh ),
_quad=sb9ThroughThicknessLobatto5(),

auto Feel::vf::sb9Shear ( ProxyType const &  proxy,
ShearWeightExprT const &  shearWeight 
)

Build the weighted physical SB9 transverse-shear strain expression.

The helper extracts the xz and yz slots from sb9Bc0, applies the supplied through-thickness shear weight, and returns a compact symmetric Mandel vector with only the transverse-shear components populated.

Example
auto shearWeight = cst( 5.0 / 4.0 ) * ( cst( 1.0 ) - zeta()*zeta() );
auto epsTrial = sb9Shear( u, shearWeight );
auto epsTest = sb9Shear( v, shearWeight );
a += integrate( _range=elements( mesh ),
_quad=sb9ThroughThicknessLobatto5(),
_expr=ddot( C, epsTrial, epsTest ) );
