Detailed Description

template<typename ElementType, OperatorType Role, template< typename > typename KernelCacheTemplate, auto Kind>
class Feel::vf::detail::SB9VectorOperator< ElementType, Role, KernelCacheTemplate, Kind >

Generic Feel++ expression node for an SB9 vector-valued contribution.

The operator is parameterized by a contribution cache and a contribution kind. It is reused by bending, pinching, and shear headers. The nested tensor performs the element-local coefficient assembly when the expression is evaluated in a variational form.

Template Parameters
ElementTypeTrial or test basis proxy element type.
RoleFeel++ basis role, either __TEST or __TRIAL.
KernelCacheTemplateContribution-specific cache template.
KindContribution selector understood by the cache.
