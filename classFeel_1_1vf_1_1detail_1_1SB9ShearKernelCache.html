Detailed Description

template<typename GeometryDataType>
class Feel::vf::detail::SB9ShearKernelCache< GeometryDataType >

Element-local cache for SB9 transverse-shear coefficients.

The cache computes the geometry-dependent auxiliary rows for the three SB9 transverse-shear blocks once per element and reuses them while Feel++ evaluates the trial/test basis coefficients. Public users normally access this through the free functions sb9Bc0, sb9Bc1, sb9Bc2 and sb9Shear.

Template Parameters
GeometryDataTypeShell cell geometry cache type provided by ShellCellGeometryTensorBase.

Fill one SB9 shear coefficient column.

The raw Bc* operator uses the local SB9 vector-operator convention: only slots 4 and 5 are written. The public sb9Shear helper maps those two slots into the compact symmetric Mandel strain vector used by the assembled elastic formulation.
