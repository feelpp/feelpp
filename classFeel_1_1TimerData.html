Detailed Description

Streaming local statistics for one tic()/toc() label.

TimerTable owns these records. Summary statistics are updated on each sample. Moments use constant storage; the equal-capacity quantile sketch retains O(k log N) values for N calls and capacity k per level. Raw samples are not retained. Recording is intended for a single thread per process.
